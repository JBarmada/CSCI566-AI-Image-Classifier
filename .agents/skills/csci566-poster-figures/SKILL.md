# CSCI 566 poster figures

Start with the current project backlog, the submitted midterm figures, and
`results/df40_transfer/poster_assets/STORY_REVIEW.md`. Ask what scientific
question each figure answers; compare existing figures with any new draft and
show the user enough context to review the complete story.

Regenerate charts from traceable saved result tables. State the sample and
aggregation unit, test condition and threshold where relevant. Show individual
holdouts when useful; do not treat repeated test images as independent data or
invent confidence intervals. Pair real false positives with fake misses.
Distinguish accuracy at a threshold from AUROC across thresholds, and avoid
asserting a cause or new scientific contribution that the evidence cannot show.
CNN and ViT differ in pretraining and training, not only architecture. Face
identity independence and mirror provenance require actual verification.

Favor a short informative title, legible labels, clearly explained lines and
symbols, and visual distinctions beyond color. Check text at intended printed
size and inspect the exported result. Provide an editable vector version when
practical; simplify a dense figure rather than shrinking it. Review the midterm
heatmap and transformation examples for possible reuse, checking rights and
data provenance. Update the backlog and cite sources for research claims.

Design references: [NIH poster guide](https://www.training.nih.gov/creating-a-scientific-poster/),
[CMU poster design](https://guides.library.cmu.edu/scienceposters/design),
[LSU accessibility guidance](https://libguides.lsuhsc.edu/posterprinting/Design).
Treat their dimensions and font recommendations as guidance, not course rules.

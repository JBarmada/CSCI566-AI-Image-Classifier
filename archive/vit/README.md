# Historical ViT starter notebooks

The k=1 and k=2 starters are retained for provenance. They predate the master
workflow and are not the starting point for new runs or resumes.

Use [ViT_Master_Experiments.ipynb](../../ViT_Master_Experiments.ipynb) for all
current k=1,2,4,7 work. Its [Python runner](../../run_vit_master.py) executes the
same notebook, and its [Slurm file](../../run_vit_master.slurm) submits that runner.
See the [ViT guide](../../docs/vit.md) for setup, resume, and outputs.

The archived notebook bytes are unchanged. Do not use them to continue the
`vit_master_v1` study or maintain parallel implementations of the current pipeline.

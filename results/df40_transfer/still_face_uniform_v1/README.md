# Exploratory common-processing follow-up

CARC job `14488912` completed with exit code 0. The same 150 source images
from [still-face v1](../still_face_v1/README.md) were converted to RGB, center
cropped to a square, resized to 512x512 with bicubic interpolation, and saved
as JPEG quality 95 with chroma subsampling disabled. The existing model-specific
preprocessing was then applied as before. The same four frozen checkpoints,
0.5 threshold, reference-replay gates, and 18-image repeat smoke were used.
No training or threshold tuning was performed.

The change combines center cropping, resizing, JPEG re-encoding and potential
loss of metadata; it is not an isolated camera, resolution or compression
experiment. The original fake files were already square and 512x512, whereas
the real photos had varied dimensions, so the geometric intervention was not
equally large across groups. The selected photos remain a small exploratory
sample with unknown identity and training overlap. These observations do not
explain the earlier DF40 error rate or establish any cause.

`manifest.csv` hashes the transformed image bytes; images are not committed.
`ACCEPTANCE.json` records replay checks, `predictions.csv` records scores, and
`paired_changes.csv` is regenerated by `compare.py`. The comparison checks both
evaluated manifest hashes, image IDs and labels and pairs each score by model,
mode, group and source path identifier.
